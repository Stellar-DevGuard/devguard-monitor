# Contributing

Please open or reference an issue before making substantial changes. Keep pull requests focused and include tests for changes to event ingestion, checkpoint durability, and RPC handling.

Run `npm ci`, `npm run check`, and `npm test` before submitting. Never include seed phrases, RPC credentials, personal information, or private infrastructure details in issues or logs.

Security issues should be reported privately to organization maintainers, rather than published with a working exploit.
